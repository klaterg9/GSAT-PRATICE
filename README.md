# GSAT 모의고사 프로그램

PDF 모의고사(텍스트 PDF, 제본 스캔본, 펼침면 스캔본)에서 문항 영역을 직접 선택해 실전처럼 풀어보는 프로그램입니다.

**📥 다운로드:** [Releases](https://github.com/klaterg9/GSAT-PRATICE/releases/latest)에서 받아 바로 실행하세요 (Python 설치 불필요).
- Windows 10/11 (64비트): `GSAT_Practice.exe`
- macOS (Apple Silicon, M1 이후): `GSAT_Practice-mac-AppleSilicon.zip` → 처음 열 때 경고가 나오면 아래 [macOS에서 처음 열기](#macos에서-처음-열기) 참고

## ⚠️ 저작권 안내

- 이 저장소는 **프로그램(소스 코드)만** 공유합니다. **도서, 문제집, 모의고사 등 프로그램 이외의 어떠한 저작권물도 포함하거나 공유하지 않습니다.**
- 저작권법에 따라 **직접 구매한 도서를 본인이 스캔하여 개인 학습 목적으로 사용하는 것을 권장**합니다.
- 프로그램으로 만든 모의고사와 내보내기 파일(`.gsat`)에 저작권이 있는 도서 내용이 들어 있다면 **다른 사람에게 배포하거나 공유하지 마세요.** 저작권물의 무단 복제·배포에 대한 책임은 사용자 본인에게 있습니다.
- 저장소의 테스트용 샘플 PDF는 포함되어 있지 않으며, `tools/make_sample_pdf.py`가 임의로 만든 가짜 문제로만 생성됩니다.

## 실행

```
pip install -r requirements.txt
python main.py
```
(PyCharm에서는 `main.py`를 열고 Shift+F10)

## 사용 순서

1. **+ 새 모의고사 만들기**: 문제 PDF를 고르고 영역별 **시작 페이지 / 끝 페이지**, 문항 수, 시간을 입력합니다.
   - 페이지 번호는 PDF 기준입니다. 펼침면 스캔본은 화면에서 왼쪽/오른쪽 쪽으로 나뉘어 보입니다.
   - 스캔본은 기울기·종이색·제본 그림자를 자동으로 보정해서 보여줍니다.
2. **문항 영역 선택**
   - 위쪽 탭에서 영역(수리/추리/지각)을 고르고, 페이지를 **스크롤**하며 문항마다 **드래그**합니다.
   - 번호는 **페이지 순서 → 위에서 아래 순서**로 자동으로 매겨집니다. 2단 편집이면 `2단 (왼쪽 단 먼저)`를 체크하세요.
   - **이어 붙이기** 버튼을 켜고 드래그하면 선택한 문항에 영역이 추가됩니다 (단/페이지를 넘어가는 지문).
     잘못 붙었으면 박스를 오른쪽 클릭 → "별도 문항으로 분리".
   - 박스를 끌면 이동, 가장자리를 끌면 크기 조절, **Delete**로 삭제.
3. **실전 응시**: 영역별 타이머와 OMR 답안지. 숫자키 1~5로 답하고 ←/→로 이동합니다.
   - 문제는 창 너비에 맞춰 크게 표시되고, `문제 크기 − / +` 또는 **Ctrl+휠**로 조절할 수 있습니다.
4. **정답 입력**: 다 풀고 제출하면 정답 입력 화면이 나옵니다. 교재 정답을 보고 입력한 뒤 **채점하기**.
   - 번호 칸을 고르고 **숫자키 1~5**를 누르면 입력되고 다음 문항으로 넘어갑니다 (Backspace: 지우기).
   - `빠른 입력` 칸에 `31425 21354…`처럼 이어서 붙여넣어도 됩니다 (건너뛸 문항은 0).
   - 입력한 정답은 저장되어 다음 응시부터는 바로 채점됩니다. 홈이나 결과 화면의 **정답 입력 / 수정**에서 고칠 수 있습니다.
5. **결과**: 영역별 점수와 문항별 풀이 시간, 오답만 다시 보기.

## 모의고사 공유 (내보내기 / 가져오기)

> 직접 만든 문제처럼 공유가 허락된 내용만 내보내서 공유하세요. 구매한 도서를 스캔한 모의고사는 본인 PC 간 백업·이동 용도로만 사용하세요.

- 홈에서 모의고사를 고르고 **내보내기 (파일로 공유)** → `이름.gsat` 파일 하나가 만들어집니다.
  문항 이미지와 (입력했다면) 정답이 들어 있고, 응시 기록과 원본 PDF는 들어가지 않습니다.
- 받는 사람은 **가져오기**를 누르거나 `.gsat` 파일을 창(또는 EXE 아이콘)에 끌어다 놓으면 됩니다.
- 가져온 모의고사는 문항 영역 수정은 안 되고(원본 PDF 필요), 정답 입력/수정은 됩니다.

## macOS에서 처음 열기

Apple 개발자 서명이 없는 앱이라 처음 열 때 "Apple에서 확인할 수 없습니다" 경고가 나옵니다.

1. zip을 풀고 `GSAT_Practice.app`을 **응용 프로그램** 폴더로 옮깁니다.
2. 앱을 한 번 열어 경고가 뜨면 **시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "그래도 열기"**를 누릅니다.
   (macOS 14 이하는 앱을 오른쪽 클릭 → **열기**도 됩니다.)
3. 또는 터미널에서 `xattr -dr com.apple.quarantine /Applications/GSAT_Practice.app`

맥에서는 데이터가 `~/Library/Application Support/GSAT모의고사/data`에 저장됩니다.
인텔 맥은 실행 파일을 제공하지 않으니 소스로 실행하세요 (`pip install -r requirements.txt` 후 `python3 main.py`).

## 배포 (GitHub Actions 자동 빌드)

버전 태그를 올리면 GitHub Actions가 **Windows EXE와 맥 앱을 빌드·자체 점검한 뒤 Releases에 올립니다.**

```
git tag v1.2.0
git push origin v1.2.0
```

- Actions 탭에서 **Run workflow**로 수동 실행하면 배포 없이 빌드만 하고, 결과물은 실행 기록의 Artifacts에서 받을 수 있습니다.
- 배포 설명은 `.github/release_notes.md`를 사용합니다.

## 직접 빌드

```
build.bat           → dist\GSAT_Practice.exe (Windows, 파일 하나)
build.bat folder    → dist\GSAT_Practice\ 폴더 (Windows, 실행이 더 빠름)
sh build_mac.sh     → dist/GSAT_Practice.app (맥에서 실행)
```

- 받는 PC에 Python이 없어도 됩니다 (Windows 10/11 64비트).
- 데이터(모의고사, 응시 기록)는 **EXE 옆 `data` 폴더**에 저장됩니다.
  EXE를 쓰기 금지된 곳(Program Files 등)에 두면 `%LOCALAPPDATA%\GSAT모의고사\data`에 저장됩니다.
- 동작 확인: `GSAT_Practice.exe --selftest` 실행 후 같은 폴더의 `selftest.txt` 확인.
